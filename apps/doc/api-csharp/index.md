# 📚 Documentation du module api-csharp

Ce module correspond au backend principal du projet TaskForce.

## Ce que tu peux faire ici:

- Développer l'API REST pour la gestion des tâches, utilisateurs, etc.
- Implémenter la logique métier dans des services dédiés.
- Ajouter des modèles de données et configurer la base (ex : Entity Framework).
- Mettre en place la communication temps réel (SignalR).
- Ajouter des contrôleurs pour exposer des routes API.
- Gérer la validation des données entrantes.
- Configurer la persistance (base PostgreSQL, migrations).
- Centraliser les constantes et routes partagées.

## Dossiers clés à créer :

- Controllers/
- Services/
- Models/
- Data/
- DTOs/
- Validators/
- Hubs/
- Shared/

N'hésite pas à compléter ce fichier au fur et à mesure de l'avancement du module !
