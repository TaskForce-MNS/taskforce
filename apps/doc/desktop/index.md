# 📚 Documentation du module desktop

Ce module correspond à l’application desktop native TaskForce (Tauri).

## Ce que tu peux faire ici

* Développer l’interface desktop en TypeScript/Rust
* Intégrer l’API backend (Api.Back)
* Gérer la communication native avec le système d’exploitation
* Ajouter des fonctionnalités spécifiques au desktop (notifications, accès fichiers)
* Personnaliser le design et l’expérience utilisateur
* Organiser le code Rust et TypeScript

## Dossiers clés à créer

* src/
* src-tauri/
* assets/
* icons/
* capabilities/

Complète ce fichier au fur et à mesure de l’évolution de l’application desktop !
