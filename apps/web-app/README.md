
# Web App (Frontend)

Ce dossier contient l’interface utilisateur principale de TaskForce.

## Rôle dans l'architecture

- Permet aux utilisateurs de gérer leurs tâches, projets et notifications en temps réel.
- Interagit avec l’API backend pour toutes les opérations métier.
- Gère l’affichage, la navigation, l’état applicatif (React, Zustand).
- Sert de passerelle entre l’utilisateur final et le cœur métier (api-csharp).

La web-app est le point d’accès principal pour la majorité des utilisateurs.
