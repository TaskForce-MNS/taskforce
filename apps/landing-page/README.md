

# Landing Page

Ce dossier contient le site vitrine de TaskForce.

## Rôle dans l'architecture

- Présente le projet, ses fonctionnalités et son équipe.
- Sert de point d’entrée public pour les visiteurs et futurs utilisateurs.
- Optimisé pour le SEO, la rapidité et l’accessibilité (Astro).
- Ne contient aucune logique métier : il s’agit d’un site statique informatif.

La landing page valorise l’image du projet et oriente les utilisateurs vers l’application principale.
